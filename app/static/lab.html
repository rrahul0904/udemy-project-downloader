Design principles

Local-first

Core calculations run in browser JavaScript. Course material is not sent to a new application backend.

Course-aware

Compatible files from the downloader can be loaded directly into the current analysis tool.

Reproducible

Tools expose copyable text, tables, equations, scripts, and transformed data instead of opaque results.

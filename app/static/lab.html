Why Study Lab belongs here

Local-first

Core calculations run in browser JavaScript and course files stay inside the application-managed archive boundary.

Course-aware

Compatible files from the downloader can be loaded directly into the current tool instead of re-uploading them elsewhere.

Reproducible

Tools expose copyable data, equations, scripts, tables, and transformed text instead of opaque results.
